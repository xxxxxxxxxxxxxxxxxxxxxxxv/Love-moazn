# PDF Word Converter

موقع صفحة واحدة لتحويل PDF إلى Word وWord إلى PDF، يعمل كواجهة ثابتة ويمكن نشره على GitHub Pages.

## المزايا
- لا يحتاج إلى حساب أو قاعدة بيانات.
- معالجة الملفات داخل المتصفح.
- PDF إلى DOCX عبر PDF.js وdocx.
- DOCX إلى PDF عبر Mammoth وhtml2pdf.js.
- عربي/إنجليزي، RTL/LTR، ووضع ليلي/نهاري.
- حد افتراضي لحجم الملف: 25 MB.

## تشغيل محلي
يمكن فتح `index.html` مباشرة في متصفح حديث. الأفضل تشغيل خادم محلي بسيط:
```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا جديدًا على GitHub.
2. ارفع جميع ملفات هذا المشروع إلى جذر المستودع.
3. افتح Settings ثم Pages.
4. من Build and deployment اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
6. انتظر رابط الموقع الذي يظهر في صفحة Pages.

ملاحظة: راجع شروط GitHub Pages قبل استخدامه لموقع يهدف إلى تحقيق دخل أو يقدم خدمة تحويل ملفات على نطاق تجاري. قد يكون من الأنسب اختيار استضافة صفحات ثابتة تسمح صراحةً بهذا الاستخدام.

## إضافة الإعلانات
مساحات الإعلانات في الصفحة مجرد مواضع تصميمية وليست إعلانات فعلية.
لاستعمال شبكة إعلانية:
1. تأكد من أن الاستضافة وشبكة الإعلانات تسمحان بنوع الموقع.
2. أضف صفحات/معلومات الخصوصية والمحتوى المطلوبين للمراجعة.
3. بعد قبول الموقع، انسخ كود الناشر والوحدة الإعلانية الحقيقيين من لوحة الشبكة.
4. أضف كود الشبكة إلى `<head>`، واستبدل موضع `.ad-slot` بوحدة الإعلان الرسمية.
5. لا تضع معرفات أو أكواد تجريبية على أنها إعلانات حقيقية.

## حدود التحويل الحالية
- PDF إلى Word يعيد بناء النص والفقرات؛ لا يضمن استنساخ التخطيط المعقد أو الصور والجداول.
- ملفات PDF المصورة/الممسوحة ضوئيًا تحتاج OCR، وهو غير مضمّن في هذه النسخة.
- Word إلى PDF يحوّل المحتوى الذي يستطيع Mammoth استخراجه إلى HTML ثم PDF؛ قد تختلف الخطوط والتخطيطات الدقيقة.
- ملفات DOC القديمة بصيغة `.doc` غير مدعومة؛ استخدم `.docx`.
- تحتاج مكتبات التحويل إلى اتصال إنترنت لأنها تُحمّل من CDN.

## الخصوصية
لا يرفع التطبيق الملفات إلى خادم خاص به. لكنه يحمّل مكتبات وخطوطًا خارجية من CDN. لا ترفع مستندات شديدة الحساسية إلى جهاز أو متصفح لا تثق به.
